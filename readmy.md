# Dostaffkin - Сервис доставки

Приложение для расчета стоимости и оформления доставки посылок с визуализацией маршрута на карте.

## Функционал

- Построение маршрута между пунктами А и Б (Яндекс.Карты)
- Расчет стоимости в зависимости от расстояния и выбранного размера посылки (XS до MAX)
- Выбор скорости доставки (Обычная / Приоритетная)
- Оформление заявки с контактными данными клиента
- Отслеживание отправления по номеру

## Технологии

- **Frontend**: Angular 19 (standalone components)
- **Карты**: Яндекс.Карты API (маршрутизация, подсказки адресов)
- **HTTP-клиент**: Angular HttpClient
- **Формы**: ReactiveForms
- **Стили**: CSS (адаптивный дизайн)
